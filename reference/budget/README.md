- **amc-budget-a-2025-26.pdf**: AMC budget 2025-26 book — budget _Licence: Municipal (AMC) publication; reproduced for reference_

- **amc-budget-index-2026-09-28.html**: AMC publishes annual budget books (English editions for some years) up to 2026-27: budget dimension _Licence: Amdavad Municipal Corporation web page; reproduced for reference_
- **amc-finance-department-about-2026-09-27.html**: AMC Finance Dept structure and officers (Dy. MC Finance, Chief Accountant) — addressee for budget/accounts RTI _Licence: Municipal (AMC) web page; reproduced for reference_

- **smc-balance-sheet-2025-26.pdf**: SMC FY26 balance sheet is a 4-page English text PDF (accrual) - budget; URL as corrected by verifier _Licence: Surat Municipal Corporation publication; reproduced for reference_
- **smc-balance-sheet-index-2026-09-28.html**: SMC publishes year-wise balance sheets 2005-06 to 2025-26 - budget _Licence: Surat Municipal Corporation publication; reproduced for reference_
- **smc-budget-book-general-board-2026-27.pdf**: SMC 2026-27 budget book is a 778-page PDF; numbers extract but legacy-font Gujarati text is garbled - budget _Licence: Surat Municipal Corporation publication; reproduced for reference_
- **smc-budget-centre-codes-2026-09-27.html**: Code list needed to map SMC budget heads/centres to departments - budget head mapping _Licence: Surat Municipal Corporation publication; reproduced for reference_
- **smc-budget-index-2026-09-27.html**: SMC budget books online only for 2021-22 to 2026-27 plus Outcome Budgets 2022-24 - budget _Licence: Surat Municipal Corporation publication; reproduced for reference; expired session tokens and visitor counter blanked_

- **smc-property-tax-recovery-stats-2006-07-to-2009-10.html**: SMC property-tax demand/recovery published only up to 2009-10, so current zone/ward figures need RTI — budget/RTI _Licence: Surat Municipal Corporation web page; reproduced for reference_
- **smc-revenue-capital-budget-summary-2026-09-28.html**: SMC weekly budget-vs-actuals feed by zone (HQ + 10 zones), last updated 27/09/2026; table body filled by JavaScript — budget dimension _Licence: Surat Municipal Corporation web page; reproduced for reference_
